# Pandanet Android UX reference
2026-11-27. Based on seven user-supplied screenshots (707 × 1536 pixels). Reference observations only; independently implement visuals and interaction. Screenshots contain account identifiers and are deliberately not committed to the public repository.

## Observations
- Full board view: square wooden board spans the entire 707 px screen width, with 19 lines per axis. Outer intersections roughly x=22 and x=684; line pitch ~36.8 px; edge padding ~22 px (~0.6 pitch). No visible coordinates. Thin dark grid and nine hoshi dots. Warm amber, subtle texture; nearly black surrounding background. Black and white stones are softly shaded, with small shadows; last move indicated by a thin contrasting ring.
- Board approximately vertically centered in the available play area. Gray top bar contains player identifiers, stone colors, clocks where visible, back and settings. Bottom dark rounded toolbar contains compact icons for zoom, chat, review, information and other actions. Toolbar changes context in review; previous/next and a numeric move selector are visible. Online/social home menu is not a feature requirement for our offline app.
- Zoom screenshot: grid pitch ~96.5 px, or ~2.62× full-board pitch. Board is clipped to viewport; neighboring stones and grid scale together. The candidate is a translucent white stone at the selected intersection, rather than a committed move. Zoom fills the area between top and bottom bars. Exact transition duration, easing, viewport anchoring near edges and gestures are not established by static frames; second-tap confirmation and independent auto-zoom-out option are user requirements from the conversation, not independently demonstrated by the screenshots.

## Our implementation targets
- Own neutral/dark visual theme, warm board, realistically shaded stones, last-move marker; no reused Pandanet assets, logo, branding or code.
- Full-board size maximizes usable square within safe area; use normalized coordinates, not hard-coded screenshot pixels. Reserve ~0.6 grid pitch outside outer intersections to avoid clipping stones. Test 9/13/19 boards separately.
- Android precision mode: proposed initial zoom factor 2.6×, adjustable if testing warrants. First tap selects and animates local zoom; transparent ghost stone with no mutation. Second tap on same point commits legal move; another intersection changes selection. Cancel without committing. Independent automatic zoom-out setting; manual return available when off. Direct input option. Use invertible camera transform for touch hit testing. Preserve selected point in view at edges; clamp camera to board boundaries. Animation duration/easing to tune on hardware, provisional ~180–250 ms with reduced-motion alternative. Never pause clock during selection. No zoom confirmation on desktop or physical electronic goban.
- Focus mode: only board, stones and clocks, no permanent toolbar or player names, hide system bars where possible. Controls revealed temporarily via clock or outside-board gesture; accessible exit. Normal view can have a compact bottom toolbar and small header. No permanent chat button in offline play. Review mode can replace toolbar with previous/next and jump-to-move, alternative branches and short explanation on request.
- Review explanations: 1–3 short sentences, relevant intersections/groups highlighted only when requested. See issue #3. Game pace and move placement animations independent of AI rank and timing.
- Test with actual Android hardware and screen sizes, including dense endgame boards, edge/corner moves, illegal moves, cancellation, orientation, clocks and reduced motion. Exact animation behavior and menu settings remain unverified.
