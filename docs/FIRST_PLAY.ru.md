# Первая игровая сборка, 27 ноября 2026

## Запуск

Для Windows x64 нужен Python 3.10 или новее с Tk и процессор с AVX2/FMA. В папке проекта выполните `py scripts/play.py --setup` один раз. Затем запускайте игру командой `py scripts/play.py`. Для Debian-совместимого Linux используйте `python3` с Tk и установленный `dpkg-deb`. Режим по умолчанию: человек играет чёрными, профиль бота 5k, китайские правила, коми 7,5. Параметры примера: `--color W --rank 3k --komi 6.5 --delay 0`.

Один щелчок ставит камень. F11 открывает полноэкранную доску с часами. Esc или нажатие на часы возвращает управление. Часы показывают использованное время каждой стороны. Настраиваемая задержка задаёт интервал между половиной и полным значением `--delay` с учётом уже затраченного на вычисление времени. Снятие флажка отключает паузы для следующих ответов. «Новая партия» отменяет текущий ответ и сбрасывает позицию. Текущая партия хранится в памяти.

## Решение по Masame

Проверен [Masame v0.8.1, ревизия 1915ecad](https://github.com/Slymaster/masame/tree/1915ecad68b0c8648fcd1b4b28228464d8454863). Исходники приложения имеют лицензию MIT. У движка, сетей и сторонних ресурсов свои уведомления. В релизе опубликованы установщик Windows, Linux-пакеты и сборки macOS. В исходниках присутствует Android workflow для ARM64. APK в проверенном настольном релизе отсутствует. См. [файлы релиза](https://github.com/Slymaster/masame/releases/tag/v0.8.1), [Android workflow](https://github.com/Slymaster/masame/blob/1915ecad68b0c8648fcd1b4b28228464d8454863/.github/workflows/android.yml) и [уведомления](https://github.com/Slymaster/masame/blob/1915ecad68b0c8648fcd1b4b28228464d8454863/THIRD_PARTY_NOTICES.md).

Masame разделяет Rust-процесс движка, разбор JSON и выбор хода в TypeScript. В `src/bot.ts` передаются humanPolicy и легальные ходы. Это возможная точка подключения профилей. Для первого эксперимента выбрана своя небольшая оболочка на Tk. Она использует существующий Python-селектор и позволяет проверить независимые ранги, задержку и физику ввода до выбора мобильного стека. В Linux запускается только CPU-движок из пакета Masame. Исходники интерфейса и графика Masame или Pandanet в проект не перенесены. [Код выбора ходов Masame](https://github.com/Slymaster/masame/blob/1915ecad68b0c8648fcd1b4b28228464d8454863/src/bot.ts).

В новой оболочке один процесс KataGo ведёт партию по GTP. Команда `kata-raw-human-nn` даёт распределение по пунктам и пасу; `play` и `showboard` возвращают фактическую позицию после взятий. Параметр humanSLProfile действует всю партию. Профиль 5k обозначает входную метку модели. Сила против реальных игроков ещё не измерена. Для будущего разбора сохранён отдельный JSON-интерфейс. [GTP KataGo](https://github.com/lightvector/KataGo/blob/v1.18.2/docs/GTP_Extensions.md).

Установщик загружает файлы с исходных адресов, указанных в `scripts/play.py`, проверяет SHA-256 и оставляет их в локальном каталоге external. [Условия для сетей KataGo](https://katagotraining.org/network_license/).

На Linux x64 (AMD EPYC 9V74) сыграна партия модели против себя. Создание сетевых сокетов IPv4 и IPv6 было запрещено с момента запуска Python и наследовалось движком. Параметры: Chinese, 19×19, коми 7,5, 5k, seed 7, Eigen CPU. Модель сделала 285 ходов, включая два паса. Оценка движка B+9,5. В одном прогоне запуск занял 2,76 с. Медиана времени выбора и применения хода составила 0,218 с, 95-й процентиль 0,273 с. Эти замеры относятся к одному компьютеру и не включают визуальную задержку.

Проверены взятие камня, запрет самоубийства, занятый пункт, запрет немедленного обратного взятия в ко, отображение позиции и пас. Отдельно пройден графический сценарий под настоящим Tk на виртуальном дисплее Linux: клик, ответ бота, новая партия во время задержки, недопустимый повторный клик, вход и выход из Focus Mode, пас и закрытие. Одноразовый JSON-запрос также вернул ход Q16 при seed 7. Воспроизведение из корня проекта после установки пакета:

```sh
python -m pip install -e ".[corpus]"
python -m unittest discover -s tests -v
python scripts/check_game.py --help
python scripts/check_desktop.py --help
```

Обе интеграционные проверки принимают те же пути `--exe`, `--config`, `--model`, `--human-model` и `--seed 7`. Проверка окна требует графического сеанса.

## Проверка на Windows

GitHub Actions выполнил проверку коммита `7c8df48` на Windows x64 с Python 3.11. Прошли загрузка и проверка пакетов, взятие камня, ко, самоубийство, занятый пункт и полная партия с seed 7. Результат совпал с Linux: 285 ходов и оценка B+9,5. Запуск игрового процесса занял 3,45 с, медиана времени на ход составила 0,360 с, 95-й процентиль 0,375 с. Отдельным шагом успешно проверены окно Tk, клик, ответ бота, новая партия во время задержки, переключение фокуса, пас и закрытие. Ubuntu выполнила все 12 модульных тестов. ## Корпус CWI

Архив занимает 47 531 846 байт, SHA-256 `514271508510ebdb83a170a2e7fdd4687fabcb9aa6bf835424f1d33876ce4e31`. Издатель обозначает записи как public domain. В репозитории сохранены код и агрегаты. [Страница коллекции](https://homepages.cwi.nl/~aeb/go/games/).

В 98 621 SGF-файле индексатор сохранил 91 829 уникальных по текущему ключу партий и 19 208 942 хода. Найдены 4 335 повторов. Исключены 1 447 партий с форой, 707 с другим размером доски, 242 пустые, 23 с расстановкой или явной сменой игрока, 19 с нарушенным чередованием и 19 с ошибками разбора. После нормализации регистра, пробелов и Unicode осталось 3 875 меток игроков.

| Точная метка в индексе | Число партий |
|---|---:|
| takemiya masaki | 1 731 |
| lee changho | 693 |
| lee sedol | 349 |

Используется главная ветка записи. Ключ учитывает размер, коми, указанную систему правил и последовательность ходов. Ходы хранятся парами байтов big-endian в координатах sgfmill, отсчёт строк снизу. Пас имеет индекс 361. Колонки member и tree_index указывают на исходную запись, sgf_date хранит дату из SGF. Таблица подсчитывает партии с точным совпадением имени для любого цвета. Транслитерации, варианты правил и совпадения между повёрнутыми позициями ещё могут скрывать дубликаты. Полная легальность каждого хода корпуса и участие в парной игре требуют отдельной проверки перед обучением.

## Следующий проверяемый результат

Подготовить первый эксперимент для Такэмии: проверить имена обоих игроков и даты, исключить командные записи, разделить выборку по целым партиям, построить базовую модель по эпохе и сравнить с ней профиль на отложенных партиях. Для приложения отдельно остаются сохранение и восстановление SGF, часы с контролем времени, сборка Android и точный ввод в два касания.
