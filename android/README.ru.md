# Go Masters для Android

Пробная версия для телефонов ARM64 с Android 8.0 и новее. Сборка также содержит x86_64 для проверки в эмуляторе. Установочный APK включает KataGo Eigen, основную сеть и Human SL. Приложение не запрашивает разрешение на интернет. При первом запуске сети копируются в закрытое хранилище приложения.

## Как играть

1. Установите GoMasters-Android.apk и откройте Go Masters. По умолчанию вы играете чёрными против профиля Human SL 5k. Доска 19×19, китайские правила, коми 7,5.
2. Коснитесь пустого пункта. Доска приблизится, и появится метка. Касание соседнего пункта переносит метку. Повторное касание выбранного пункта ставит камень. В увеличенном виде доску можно передвигать пальцем.
3. Нажмите на часы, чтобы пасовать, начать новую партию, изменить сенсорный ввод или включить режим фокуса. В режиме фокуса остаются доска и часы. Android Back отменяет выбор. Автоматическое отдаление и ввод одним касанием настраиваются отдельно.
4. Новая партия позволяет выбрать цвет и ранг от 20k до 9d. При двух пасах выводится оценка KataGo. Последняя партия восстанавливается после закрытия приложения. Часы считают проведённое в игре время без ограничения на ход.

## Сборка и проверка

GitHub Actions собирает нативный интерфейс на Java, GTP-движок для ARM64 и x86_64, проверяет подпись и выравнивание APK. В тестовом APK используется отладочная подпись, создаваемая при сборке. Для установки обновления поверх предыдущей сборки требуется тот же ключ. Удаление приложения удаляет локальную партию.

Для воспроизведения используйте команды в [Android workflow](../.github/workflows/android.yml). Рецепт ARM64 закреплён на Masame 1915ecad, KataGo на fd0723fd, Android NDK на 27.2.12479018. Контрольные суммы обеих сетей берутся из scripts/play.py. Уведомления и лицензии входят в assets/notices. Ключ подписи, бинарные зависимости и модели хранятся вне дерева исходного кода. Команда `python3 android/tests/device.py` выполняет проверку на подключённом тестовом устройстве: сбрасывает данные Go Masters, включает авиарежим и воспроизводит партию до первого ответа бота.

## Что проверять на телефоне

Доступность пунктов у краёв, удобство масштаба, время первого ответа, расход батареи и нагрев после получаса игры. Числа настольного процессора не характеризуют телефон. Android является основной платформой. ПК используется для подготовки моделей и проверки выбора ходов. Именные профили мастеров и объяснения ходов остаются следующими этапами.

## Просмотр партии и SGF (ветка android/review-sgf, 27.11.2026)

В меню часов выберите «Просмотр партии / SGF». Открывается отдельный экран с доской, номером и координатой хода, ползунком и кнопками перехода в начало, назад, вперёд и в конец. Восстанавливаются захваты одиночных камней и групп. Пас не изменяет доску. Просмотр не изменяет игровую позицию и не обращается к движку. Если открыть его до окончания партии, показывается снимок истории на момент открытия; текущая партия и её часы не останавливаются.

Кнопка SGF открывает стандартный Android-диалог сохранения файла. Формат FF[4], 19×19, китайские правила, коми 7,5. Сохраняются все принятые движком ходы и пасы снимка, без неподтверждённого результата. Импорт SGF, библиотека нескольких партий, вариации и оценки KataGo ещё не реализованы. Локальное воспроизведение доверяет проверке ко/суперко в исходной GTP-сессии и не является валидатором произвольного SGF.

### Проверка
```sh
mkdir -p /tmp/gomasters-tests
javac --release 8 -encoding UTF-8 -d /tmp/gomasters-tests android/src/org/gomasters/mobile/GameRecord.java android/tests/GameRecordTest.java
java -cp /tmp/gomasters-tests org.gomasters.mobile.GameRecordTest
```
Результат локального JVM-теста: GameRecord tests passed (JDK 21, --release 8; хеши исходников совпадают с GitHub). Проверены захваты обоих цветов, группа, пас, границы, SGF, неизменность снимка, неверные точки и суицид. Тест добавлен в android/build.sh. Полная сборка APK и интерфейс на Android в этой сессии не проверены: локального SDK и доступа к git clone нет. Перед слиянием проверить GitHub Actions, затем реальный телефон: просмотр после захвата и двух пасов, сохранение/отмена в системном диалоге, открытие SGF в другом клиенте.

Следующий шаг: отдельная оценка выбранной позиции KataGo, затем краткое объяснение слабостей и альтернативных ходов по реальным результатам расчёта, без вмешательства в текущую игровую сессию.

## Первый вариант наставника: разбор выбранного хода

После двух пасов откройте «Просмотр партии / SGF», выберите ход и нажмите «Разбор». Показывается позиция **перед** выбранным ходом; зелёное кольцо отмечает предложение KataGo, синее — сыгранный пункт. Пас обозначается текстом, а не кольцом. При выборе нулевого хода анализируется начальная позиция. Закрытие окна отменяет расчёт. Во время обычной партии кнопка разбора отключена.

Игровой процесс KataGo закрывается после получения итоговой оценки. Разбор использует отдельный процесс `katago analysis`, стандартную сеть и локальный JSON-протокол v1.18.2, без Human SL, сервера или LLM. Передаётся точная последовательность ходов, китайские правила, коми 7,5. Рекомендация выбирается по `order` движка, не по максимальной оценке очков. Базовый поиск ограничен 64 посещениями. При недостатке посещений сыгранного/рекомендованного пункта выполняются два ограниченных поиска по 32 посещения с `allowMoves` до глубины 1. Лимит каждого запроса 120 секунд; результат не гарантирован. Числа приведены к перспективе цвета, которому принадлежит ход (в конфигурации вывода фиксирована перспектива чёрных).

Шаблоны отвечают в 1–3 предложениях: предложение, осторожное сравнение очков, подтверждённая проверкой дыханий тактика, если применимо. Разница менее 2 очков не маркируется как ошибка; минимум 12 посещений на вариант — эвристика, не статистическая гарантия. Не выдаются предположения о жизни/смерти группы или стратегических причинах без подтверждения. При предупреждении движка (например, о подмене правил), неверном ответе или отмене рекомендации не выдаются.

**Валидация:** CoachTextTest прошёл локально (JDK 21, --release 8), SHA-1 Git blob обеих локальных копий совпадает с GitHub: CoachText.java 6eac4eb9e1fb9cbc61d4ee43a66d7f03f1dda07a; CoachTextTest.java 46effa818b1caa78981e6ceb2e68ce227cc453ec. Проверены оба цвета, порядок вариантов, координаты, пас, слабые данные, захват и атари. Тест включён в build.sh. Нативная JSON-интеграция, Android UI, производительность, нагрев, сборка APK и физический телефон пока не проверены. Для приёмки: завершить партию, выбрать ранний и поздний ход за оба цвета, проверить соответствие доски, колец, текста, принудительных поисков и отмены; сравнить ответ с настольным KataGo на той же позиции. Порог посещений и разницы очков предварительный.

Источники протокола: [Analysis Engine v1.18.2](https://github.com/lightvector/KataGo/blob/v1.18.2/docs/Analysis_Engine.md), [analysis_example.cfg](https://github.com/lightvector/KataGo/blob/v1.18.2/cpp/configs/analysis_example.cfg).

Следующие функции наставника: карты ownership, выделение слабых групп по всей доске, варианты продолжения и содержательные стратегические пояснения. Текущая версия не заменяет полноценный анализ жизни и смерти.

## Карта владения, атари и варианты (следующий этап)

На экране разбора доступны три дополнительные кнопки. «Карта» показывает прогноз владения пунктами к концу игры (ownership, 361 значение в порядке от A19 до T1). Перспектива вывода фиксирована на BLACK. Тёмные квадраты обозначают прогноз в пользу чёрных, светлые — белых. Насыщенность пропорциональна модулю оценки, значения с модулем менее 0,15 скрываются. Это визуальная эвристика, не окончательный подсчёт территории и не вероятность победы. Используется карта исходного свободного поиска, а не принудительно выбранной альтернативы.

«Атари» отмечает все группы обоих цветов с ровно одним уникальным дыханием. Оранжевые кольца на камнях, жёлтые на последнем дыхании; текст показывает число групп каждого цвета. Группы с несколькими дыханиями могут оставаться стратегически слабыми. Атари само по себе не доказывает гибель группы. Карта и атари взаимно исключают друг друга; повторное нажатие убирает слой.

«Варианты» показывает до трёх непустых PV свободного поиска по порядку KataGo, до восьми ходов на вариант. Кнопки и ползунок позволяют просматривать отдельную гипотетическую запись начиная с исходной позиции. Сыгранная партия и SGF не меняются. Варианты с менее чем 12 посещениями помечаются как слабо рассчитанные. PV не гарантирует оптимальность или вынужденность. Воспроизведение проверяет занятость и суицид, но доверяет движку в части ко/суперко. Несовместимый с локальным воспроизведением вариант не показывается.

## Приёмка устанавливаемой Android-сборки

Добавлена подтверждаемая сдача на своём ходу: «Часы → Сдаться». Результат сохраняется при перезапуске, разбор доступен без возобновления игры. SGF содержит RE[W+R] или RE[B+R] в зависимости от цвета сдавшегося игрока; два паса пока не экспортируют оценку как утверждённый результат. При новой партии состояние сдачи сбрасывается.

Android workflow теперь запускается для PR с изменениями Android и для push в main, а также вручную. Первый job preflight выполняет три набора JVM-тестов, проверяет синтаксис Python и shell, компилирует Java-код с Android SDK 35 до затратной сборки NDK. Второй job собирает подписанный APK и проверяет его на эмуляторе API 30 в авиарежиме: реальный ответ Human SL, корректировка точки, фокус, восстановление игры, отмена сдачи, сдача, повторное восстановление, разбор хода настоящим KataGo, карта, атари и просмотр PV. Публикация артефакта GoMasters-Android происходит после успешного теста. При сбое собираются доступные диагностические файлы (logcat, XML, снимок экрана). Тест сбрасывает данные приложения, запускать только на тестовом устройстве.

Текущие изменения сохранены в PR #4. В этой сессии локального SDK нет, сетевое клонирование GitHub из контейнера недоступно. Новые тесты и полный workflow ещё не подтверждены как прошедшие. Не считать сборку проверенной до зелёного статуса обоих jobs. Проверка SGF через системный диалог и импорт во внешнем клиенте, замеры на ARM64, нагрев, расход батареи, Android 16 и стабильный ключ обновлений остаются ручными критериями приёмки. APK, подписанные разными preview-ключами, не обновляются поверх друг друга; не удалять установленную игру без предварительного экспорта SGF.
